✨ Características de la App

📊 Dashboard

  • Estadísticas en tiempo real
  • Ingresos, gastos y ganancias
  • Resumen del día y mes
  • Pull-to-refresh

🚗 Trabajos

  • Registrar nuevos trabajos
  • Asignar trabajadores
  • Datos de clientes y vehículos
  • Historial completo

💵 Finanzas

  • Control de ingresos
  • Gestión de gastos
  • Categorización
  • Totales acumulados

👥 Trabajadores

  • Lista de empleados
  • Crear y editar
  • Gestión de salarios
  • Estado activo/inactivo

🚀 Para Empezar

cd mobile-app
npm install
cp .env.example .env
# Edita .env y configura API_URL
npm start

Luego escanea el código QR con Expo Go en tu iPhone o Android.
